ABOUT SIDs FILES
================================================================================

The auditor uses two SID lookup files to verify client names:

  SIDs.csv          -- Used for OAS CAHPS audits
  HCAHPS_SIDs.csv   -- Used for HCAHPS audits

Both files map SID codes to client names. The auditor works without them,
but SID registry checks will be skipped.

--------------------------------------------------------------------------------
WHERE TO PUT THEM:

Place both files in your installation folder:

  %LOCALAPPDATA%\OAS-CAHPS-Auditor\SIDs.csv
  %LOCALAPPDATA%\OAS-CAHPS-Auditor\HCAHPS_SIDs.csv

(On most systems %LOCALAPPDATA% is C:\Users\<your name>\AppData\Local)

If Windows asks whether to overwrite an existing file, click Yes.

--------------------------------------------------------------------------------
UPDATING THEM (when new clients are added):

1. Download the latest version from the link above.
2. Replace the existing file in your installation folder.
3. That's it -- the auditor will use the new version automatically.

When you update either file, please upload the new version back to OneDrive
so all other users get the update too.
